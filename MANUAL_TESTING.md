# Remaining iPad verification

Automated production checks run in desktop Chrome with tablet/phone viewport sizes. Verify the following on an actual iPad Safari/Home Screen app:

1. Install from HTTPS using Share → Add to Home Screen. Confirm the centered icon, readable header below system chrome, and reachable controls in portrait/landscape and split view.
2. Use finger and Pencil on saturation/value and hue. Open/close both drawers; scroll each panel and main content independently. Check all numeric fields, HEX paste, and native color selection.
3. Drag the gold key light with finger and Pencil around all sides of the anime portrait and Materials preview. Confirm that lit planes face the source and bangs/nose/chin cast away from it. Change Front depth, then use angle/depth sliders and arrow keys on the focused light. At zero strength the preview should be unchanged by light direction. Confirm that the source control is reachable and stays clear of the artwork controls in portrait and landscape.
4. Compare Cel / 赛璐璐 and Painted / 半厚涂, all time-of-day lights, and all four shadow finishes. Try all eight palette looks with some and all colors locked. Palette looks must preserve locks/light/finish; shadow finishes must preserve every base color and source position. Try undo/redo and export/import after each kind of preset. Compare Values mode and old version-2 saved studies/backups.
5. Test locking, harmony generation, extraction from several local images, all locked colors, add/remove colors, grayscale/black/white anchors, and undo/redo.
6. Save/reload/load/remove library entries. Export JSON, palette PNG, and illustration PNG through Safari's download/share flow. Reimport the original palette PNG and JSON, and verify names, locks, and lighting. Try a malformed or oversize file and confirm the previous study survives.
7. Follow device theme while switching iPad appearance. Check both explicit themes and rotation with the keyboard or system file picker open.
8. Wait for offline-ready status. Close/reopen in airplane mode, edit colors, extract a local image, load a palette, and export a PNG. Return online before checking updates.
9. Open a newer build, allow it to cache, close all ArtLab app windows/tabs, and reopen. Verify saved studies remain. Check FoldLight independently; both apps must preserve their own library/cache.
